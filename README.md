# Snipbird

Snipbird is private clipboard memory for macOS. It keeps copied text, links,
images, and Finder files searchable, then adds local actions, Session Copy, and
reusable message templates.

This public repository contains downloads, release notes, support documents,
and the Snipbird website. It does not contain the Snipbird application source
code.

## What Snipbird does

- Searchable clipboard history for text, links, images, and files
- AES-256-GCM encrypted history with the key stored in macOS Keychain
- Local transformations for text, JSON, URLs, files, and screenshot OCR
- Session Copy for collecting values and pasting them into fields in order
- Reusable templates with fill-in-the-blank fields
- Signed automatic updates and a guided first-run tutorial

Snipbird 1.3 adds one unified Palette for Recent, Pinned, and Templates, visual
previews, contextual actions, and direct `Command-R`, `Command-P`, and
`Command-T` section shortcuts.
