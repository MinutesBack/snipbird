How can we help?

Most Snipbird problems can be reproduced and fixed without sharing private clipboard content.

Before reporting a problem

  1. Confirm Snipbird is running and the bird appears in the menu bar.
  2. Install updates from the Mac App Store, or use Check for Updates in the direct edition.
  3. Reproduce the problem once and note the exact steps.
  4. Check whether an existing report describes the same behavior.

Report a bug

Include the Snipbird version, macOS version, Mac processor, what you expected, what happened, and reproduction steps. Do not post clipboard contents, passwords, personal information, or encryption keys.

Password prompt

Snipbird keeps its encryption key in macOS Keychain. A genuine system dialog may appear once after a signing change. Select Always Allow so macOS remembers the approved Snipbird signature. Snipbird never receives your Mac password.

Privacy

Read the Snipbird Privacy Policy. Clipboard content remains on your Mac.
