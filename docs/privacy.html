Privacy is the product.

Snipbird processes clipboard content on your Mac. MinutesBack does not receive it.

Data Not Collected

No account, advertising, analytics, tracking, or clipboard-content service. Your clipboard is never uploaded to MinutesBack.

Stored on your Mac

Snipbird may store copied text, links, images, file references, source-app names, pins, favorites, templates, and preferences. Clipboard history and captured images use AES-256-GCM encryption. The key stays in the macOS Keychain on that Mac and does not sync through iCloud.

Templates remain readable local JSON so you can intentionally import, export, and share them.

Confidential copies

Snipbird skips items that compatible password managers mark as transient or confidential. You can also block selected applications from clipboard capture.

Network access

Mac App Store edition: no network requests. Apple provides updates through the Mac App Store.

Direct edition: Sparkle checks the public MinutesBack release feed on GitHub for signed updates. GitHub may receive ordinary connection information such as an IP address and user agent.

Support and deletion

If you report a problem, you choose what to submit. Never include clipboard contents, passwords, or encryption keys in a public issue.

Clear clipboard history from Snipbird Settings. Removing Snipbird and its application container removes locally stored App Store data.

Questions: Snipbird Support.
