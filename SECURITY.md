# Security

Do not publish a security vulnerability, clipboard content, encryption key, or
other secret in a public issue.

For ordinary bugs, use the Snipbird issue form. For a security report, open a
GitHub private vulnerability report from the Security tab when that option is
available. Include the affected version, impact, and reproduction steps.

Snipbird release archives are distributed only from the official MinutesBack
release page. Version 1.3 and later must be signed with a MinutesBack Developer
ID certificate, notarized by Apple, and signed for Sparkle updates before
publication.
